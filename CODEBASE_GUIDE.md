# Bible Plan — Codebase & Architecture Guide (for AI Agents & Developers)

This document explains every directory, route, page, component, context, library module, storage key, custom browser event, submodule, build script, and test in **Bible Plan** so an AI agent or developer can orient quickly and modify the codebase safely.

---

## 1. High-Level Architecture

- **Framework & Tooling**: React 18 + Vite 5 + React Router 6 (`src/main.jsx`, `src/App.jsx`).
- **Hosting / Deployment**: Static SPA hosted on Vercel (`vercel.json` rewrites all routes to `/index.html`).
- **Persistence Model**: **100% on-device** (`localStorage`) via `src/lib/deviceStorage.js`. There is **no backend, no database, and no user accounts**.
- **Scripture Sources**:
  - **HelloAO** (`https://bible.helloao.org/api`) — free/open translations (`BSB` default, `WEB`, `KJV`, `ASV`, etc.).
  - **API.Bible** (`https://rest.api.bible/v1` / fallback `https://api.scripture.api.bible/v1`) — requires optional `VITE_API_BIBLE_KEY` (`NIV`, `NLT`, `NLT-UK`, `CSB`).
  - **YouVersion Platform Core** (`@youversion/platform-core`) — with automatic fallback to HelloAO on failure.
  - **Static Extra Books** (`/public/extra-books/{BOOK_ID}/{chapter}.json`) — self-hosted JSON for Deuterocanonical, Orthodox, Ethiopian Orthodox, OT Pseudepigrapha, and NT Apocrypha collections, with a graceful "Coming soon" fallback for unpopulated chapters.
- **Reading Plan Data**: `Bible-CSV/` git submodule (`https://github.com/jasonhukom/Bible-CSV.git`) bundled at build time via Vite `?raw` imports (`src/lib/bibleCsvBundle.js`), plus dynamic translation-aware generation (`src/lib/planGenerator.js`).

## 4. Context Providers (`src/context/`)

### `src/context/ThemeContext.jsx`
- **Exports**: `THEMES` (18 theme definitions with `id`, `label`, `swatches`), `ThemeProvider`, `useTheme()`.
- **State & Persistence**: Stores selected theme ID in `localStorage["bible-plan-theme"]` (default `"dark"`). Applies `data-theme="<id>"` to `document.documentElement` so CSS custom properties in `src/styles/global.css` update immediately.

### `src/context/CalendarViewContext.jsx`
- **Exports**: `CalendarViewProvider`, `useCalendarView()`.
- **State**: `viewYear`, `viewMonth` (0–11), `selectedDate` (`"YYYY-MM-DD"`), `todayString`.
- **Actions**: `setSelectedDate`, `goToMonth(year, month)`, `goToPrevMonth()`, `goToNextMonth()`, `goToToday()`, `goToDate(dateStr)`.
- **Mounted inside**: `Layout.jsx` (shared by `Sidebar`'s `MiniCalendar` and `PlanPage`).

### `src/context/PlanContext.jsx`
- **Exports**: `PlanProvider`, `usePlan()`.
- **Default Config**:
  ```js
  {
    name: "My reading plan",
    start_date: todayDateString(),
    days: 365,
    book_groups: ["ot", "nt"],
    order_mode: "overlap",
    chronological: false,
    daily_psalms: false,
    daily_proverbs: false
  }
  ```
- **State**: `plan`, `rows` (flat array of chapter rows), `scheduleByDate` (`Map<dateString, Row[]>` sorted by `position`), `loading`, `generating`, `error`.
- **Row Shape**:
  ```js
  {
    id, day_index, date, book, book_name, chapter,
    category, // "ot" | "dc" | "nt"
    position, completed, completed_at
  }
  ```
- **Actions**:
  - `regenerate(config, options)`: Calls `generateSchedule(...)`, turns schedule days into rows (marking `options.preCompletedBooks` as already completed), and persists both plan and rows via `deviceStorage.saveActivePlan` / `deviceStorage.replaceSchedule`.
  - `toggleChapter(row)`: Flips `completed` / `completed_at` and writes updated rows to `deviceStorage`.
  - `moveRowsToDate(rowIds, newDate)`: Moves whole-book pills or individual chapters to `newDate`, recalculating `day_index` and appending sequential `position` values, then persists via `deviceStorage`.

## 5. Pages (`src/pages/`)

### `src/pages/PlanPage.jsx`
The main Google-Calendar-style monthly reading tracker.
- **Calendar Grid**: Uses `buildMonthGrid(viewYear, viewMonth)` (42 cells, 6x7 Sunday–Saturday). Calls `pillsForDate(rows)` to collapse each book's chapters on a day into contiguous ranges (e.g., `9, 20-21`), displaying up to `MAX_VISIBLE_PILLS = 3` per cell plus a `+{n} more` button. Marks a day cell `.done` when all scheduled rows on that date are completed.
- **Drag-and-Drop Rescheduling**: Dragging a book pill drags all its `rowIds` (`{ type: "book", rowIds }`); dragging a chapter inside the day detail panel drags `{ type: "chapter", rowIds: [row.id] }`. Dropping on any day cell calls `moveRowsToDate`.
- **Day Detail Panel**:
  - Desktop (`!isMobile`): Collapsible & resizable right-hand `.bible-sidebar` (`sidebarWidth` 120–600px; dragging below 120px collapses it).
  - Mobile (`isMobile`, `< 720px`): Modal `.cal-overlay` popup (`.day-detail-popup`).
  - Each chapter item has a completion toggle checkmark and a "Direct to Bible" button navigating to `/bible/${getPreferredTranslation()}/${row.book}/${row.chapter}`.
- **Navigation Inputs**:
  - **Keyboard**: `ArrowLeft` -> previous month; `ArrowRight` -> next month (ignored inside `INPUT`/`TEXTAREA`/`SELECT`).
  - **PC Mouse Scroll**: Non-passive `wheel` listener on `.plan-main` (active when `!isMobile && !showOnboarding`, ignores `ctrlKey`/`metaKey` zoom and horizontal gestures) powered by `createWheelMonthNavigator()`: **scroll up** (`deltaY < 0`) -> **next month**, **scroll down** (`deltaY > 0`) -> **previous month**, with threshold & cooldown preventing multi-month trackpad jumps.
  - **Mobile Touch Swipe**: Horizontal touch swipe (`handleTouchStart`, `handleTouchMove`, `handleTouchEnd`) on `.calendar-grid-wrap` with spring-back transform.
- **Bottom Bar**: Quick dark/light theme toggle, live clock (12h/24h toggle persisted in `localStorage["bible-plan-time-format"]`), month arrows, and `Today` button.
- **Onboarding**: Shows `<OnboardingModal />` if `localStorage["bible-plan-onboarded"]` is unset.
- **Live Settings**: Reads `dateNumberPosition` (`"left" | "center" | "right"`) from `deviceStorage.getSettings()` and subscribes to `"bible-settings-changed"`.

### `src/pages/BiblePage.jsx`
Full Bible reader supporting desktop side-panel navigation, inline mobile navigation, bottom sheets, extra book collections, reading history, and verse saving.
- **Navigation & URL Sync**: Reads `:translationId`, `:bookId`, `:chapter` params; falls back to `getPreferredTranslation()` (`"BSB"`). Listens to `"bible-translation-changed"` and `"bible-extra-books-changed"`.
- **Book List & Filtering**:
  - Desktop collapsible & resizable left book sidebar (auto-collapses when a chapter opens) with alias search (`matchesBookSearch`), testament tabs (`All`, `OT`, `NT`), and order tabs (`Trad`, `A–Z`).
  - Mobile inline header (`.bible-inline-mobile-header`) with inline expandable book/chapter pickers plus access to `BibleTranslationsSheet`, `BibleBooksSheet` (History tab), and `BibleFontSheet`. (`BibleMobileTopBar` is also rendered in JSX, hidden via CSS on mobile in favor of the inline header).
- **Chapter Reader**:
  - Renders `heading`, `line_break`, `verse`, and `hebrew_subtitle` items from `getChapter(...)`.
  - Applies reader settings (`fontSize`, `lineHeight`, `fontFamily`, `readerTheme`: `"dark" | "paper" | "oled"`) saved in `localStorage["bible-reader-settings"]`.
  - Records up to 30 recent chapters in `localStorage["bible-reading-history"]`.
  - Shows "Source: ..." attribution and a "Coming soon" banner when viewing unpopulated extra books, or a quick-enable banner if an extra book's collection is currently turned off.
  - Supports Prev/Next chapter buttons, `BibleFloatingNav` circular edge buttons, and Left/Right keyboard arrows.
- **Tap-to-Save Verses**: Clicking any verse calls `toggleVerse(verseNumber, verseText)` which adds/removes the verse in `deviceStorage` (`saveVerse` / `unsaveVerse`) and displays a floating toast notice.

### `src/pages/SavesPage.jsx`
Lists all saved verses from `deviceStorage.listSavedVerses()` in chronological save order (oldest first). Each card links back to `/bible/${translation}/${book}/${chapter}` and provides a `Remove` button (`deviceStorage.unsaveVerse(id)`). Subscribes to `"bible-saved-verses-changed"`.

### `src/pages/ProfilePage.jsx`
Local-only profile manager stored on device:
- Displays/edits `display_name` (`deviceStorage.updateProfile`).
- Allows picking an image file -> crops in `<ImageCropperModal />` -> scales to max 256px JPEG data URL via `deviceStorage.saveAvatarBlob` -> saves on device (`avatar_url`). Includes a `Remove photo` button when an avatar exists.
- Shows saved verse count (linking to `/saves`) and a top-right Settings gear button (linking to `/settings`).

### `src/pages/SettingsPage.jsx`
Three settings cards:
1. **Appearance**: 18-theme swatch grid (`useTheme()`).
2. **Calendar**: Cell date number alignment (`left`, `center`, `right`), saved via `deviceStorage.saveSettings({ preferences: { dateNumberPosition } })`.
3. **Default translation**: Dropdown populated by `listTranslations()`, saved via `setPreferredTranslation(id)` and `deviceStorage.saveSettings({ translation: id })`, plus link to `/licenses`.

### `src/pages/LicensesPage.jsx`
Static copyright/public-domain notices (NIV, BSB, KJV/ASV/WEB) and API provider notes (API.Bible, YouVersion API) with a back link to `/settings`.

## 7. Library Modules (`src/lib/`)

### Persistence & Storage
- **`src/lib/deviceStorage.js`**:
  Central on-device persistence API wrapping `localStorage` with quota recovery (automatically evicts `bible-extra-chapter-v1-*` cached chapter entries if `setItem` hits quota).
  - Exports `STORAGE_KEYS` and `deviceStorage`:
    - Plan & schedule: `getActivePlan`, `saveActivePlan`, `listSchedule`, `replaceSchedule`, `setChapterCompleted`, `moveScheduleEntries`.
    - Profile: `getProfile`, `updateProfile`, `saveAvatarBlob` (canvas-resizes to max 256px JPEG data URL).
    - Settings: `getSettings`, `saveSettings`.
    - Saved verses: `listSavedVerses`, `saveVerse`, `unsaveVerse`.

### Reading Plan & `Bible-CSV` Submodule
- **`Bible-CSV/`**: Git submodule tracking `https://github.com/jasonhukom/Bible-CSV.git`. Contains 12 365-day CSV files (`order*.csv` and `overlap*.csv`, with combinations of `-chronological`, `-psalm-proverbs`, `-deuterocanonical`). Format per row: `"YYYY-MM-DD","Gen 1-2; Mat 1; Ps 1; Pro 1","<verseCount>"`.
- **`src/lib/csvPlanParser.js`**: Pure ESM CSV parser & token mapper (safe in both Vite and Node):
  - `CSV_BOOK_TOKEN_TO_ID`: Maps all 73 `Bible-CSV` tokens (including `Jud` -> `JDT`, `Jude` -> `JUD`, `Phm`/`Phlm` -> `PHM`, `Sos` -> `SNG`, `1 Es`/`2 Esd`/`AddEst`/`LetJer`/`S3y`/`Sus`/`Bel`/`Man`/`Tob`/`Wis`/`Sir`/`Bar`/`1-4 Mac`, and bare `Ps` -> `PS2` Psalm 151).
  - `getCsvPlanFilename({ orderMode, chronological, dailyPsalms, dailyProverbs })`.
  - `parsePassageSegment`, `parsePassageCell`, `parseCsvPlanText(csvText, startDate)`, `extractChronologicalStreams(csvText)`.
- **`src/lib/bibleCsvBundle.js`**: Imports the 8 canonical/chronological/psalm-proverb CSVs from `../../Bible-CSV/*.csv?raw` for Vite bundling.
- **`src/lib/csvLoader.js`**: Loads CSV text from `bibleCsvBundle.js` in browser/Vite, or from `Bible-CSV/` on disk using dynamic `@vite-ignore` Node `fs/promises` during `npm test` (so Vite builds emit zero extra CSV files or warnings).
- **`src/lib/planGenerator.js`**:
  - Uses exact `Bible-CSV` files when `days === 365`, both `ot` & `nt` selected, and `excludeBooks` is empty (handling single-toggle `dailyPsalms` or `dailyProverbs` by starting from the base CSV and appending the selected daily wisdom book).
  - For custom `days`, single testaments, or `excludeBooks`: extracts chronological OT/NT streams from `order-chronological.csv` (when `chronological === true`) or builds live canonical pools via `listBooks(translationId)` (when `chronological === false`), chunks evenly via `chunkEvenly`, and appends daily Psalms (1–150 cycle) / Proverbs (1–31 cycle) if enabled.
  - Also exports `groupIntoRefs(entries)` for merging contiguous chapter runs.

### Calendar & Image Helpers
- **`src/lib/calendarGrid.js`**:
  - `buildMonthGrid(year, month)`: Always returns 42 `{ date, day, isCurrentMonth }` cells (Sunday-start).
  - `monthLabel(year, month, short)` & weekday label constants.
  - `createWheelMonthNavigator({ threshold, cooldownMs, idleResetMs })`: Converts desktop `wheel` deltas (`deltaY < 0` -> `"next"`, `deltaY > 0` -> `"prev"`) with line/page `deltaMode` normalization and cooldown protection.
- **`src/lib/cropImage.js`**: `getCroppedImg(imageSrc, pixelCrop, rotation, flip)` renders cropped canvas to a JPEG `Blob`.

### Bible APIs & Book Metadata
- **`src/lib/bible.js`**: Unified Bible router (`DEFAULT_TRANSLATION_ID = "BSB"`).
  - `getPreferredTranslation()` / `setPreferredTranslation()` (`localStorage["bible-translation"]` + `"bible-translation-changed"` event).
  - `getTranslationShortName(translationObj, fallbackId)`.
  - `listTranslations()`: Combines API.Bible + HelloAO (English) + YouVersion (`yv-1`, `yv-12`, `yv-206`, `yv-3034`).
  - `listBooks(translationId, activeToggles)`: Routes to `apibible`, `youversion` (with HelloAO fallback), or `helloao` (with BSB / `apibible` fallback), then merges active extra books via `mergeBooksWithExtras`.
  - `getChapter(translationId, bookId, chapterNumber)`: Routes extra books to `getExtraChapter`, else `apibible` / `youversion` (with HelloAO fallback) / `helloao`.
- **`src/lib/helloao.js`**: Cached JSON client for `https://bible.helloao.org/api`.
- **`src/lib/apibible.js`**: API.Bible REST client (`VITE_API_BIBLE_KEY`) + HTML DOM parser + `STANDARD_CHAPTER_COUNTS` offline fallback.
- **`src/lib/youversion.js`**: `@youversion/platform-core` `ApiClient` client + HTML parser.
- **`src/lib/bibleBooks.js`**: `OT_IDS`, `NT_IDS`, `classifyBook`, `GROUP_LABELS`, `GROUP_COLORS`, `BOOK_NAMES`, `BOOK_SHORT_NAMES`, `getLongBookName`, `getShortBookName`, `groupBooks`.
- **`src/lib/extraBooksRegistry.js`**: Definitions for `EXTRA_COLLECTIONS` (`DC`, `ORT`, `ETH`, `PSE`, `NTA`), `EXTRA_BOOKS`, `resolveBookPlacement`, `getEnabledExtraBooks`, `getWhereTheyGoPreview`, `mergeBooksWithExtras`, `matchesBookSearch`.
- **`src/lib/extraBooksApi.js`**: Persists extra collection toggles (`localStorage["bible-additional-books-toggles"]`), dispatches `"bible-extra-books-changed"`, caches static `/extra-books/{book}/{ch}.json` in memory + `localStorage["bible-extra-chapter-v1-*"]`, and falls back to `isComingSoon: true` chapter objects.

## 10. Tests & Build Commands

## 11. Notes & Gotchas for AI Agents

1. **Submodule Checkouts**: Ensure `Bible-CSV/` is initialized (`git submodule update --init --recursive`) after cloning, otherwise Vite imports in `src/lib/bibleCsvBundle.js` and `tests/csvPlanGenerator.test.js` will miss the CSV files.
2. **Node vs Vite Compatibility in `src/lib/`**: Test scripts run directly under `node`. Keep Vite-only `?raw` / `import.meta.glob` imports isolated inside `src/lib/bibleCsvBundle.js` and avoid static `new URL("../../Bible-CSV/...", import.meta.url)` patterns in files Vite bundles, or Vite will emit duplicate CSV files into `dist/assets/`.
3. **Browser APIs in `BiblePage.jsx` / `apibible.js` / `youversion.js`**: `DOMParser` is used in chapter HTML parsing (`apibible.js`, `youversion.js`), and `window` / `document` / `localStorage` in UI/storage modules. Pure logic functions accept custom storage mocks (`deviceStorage.js`) or run without DOM (`csvPlanParser.js`, `calendarGrid.js`, `extraBooksRegistry.js`).
4. **Mobile vs Desktop UI Quirks**:
   - Mobile breakpoint is `< 720px` (`window.innerWidth < 720` in `PlanPage.jsx` and `@media (max-width: 719px)` in `global.css`).
   - On mobile, Settings (`/settings`) is reached via the Profile page's top-right gear icon (`ProfilePage.jsx`), while the mobile bottom nav has Reading Plans, Saved, Home (`/plan`), Bible, and Profile.
   - Do not break `Sidebar.jsx`'s sync with `ProfilePage.jsx` (`"bible-profile-changed"`) or `PlanPage.jsx`'s sync with `SettingsPage.jsx` (`"bible-settings-changed"`).
